# 🥗 NutriBuddy

**NutriBuddy is a kid-friendly nutrition and healthy-habits mobile app designed to help children build positive relationships with food, hydration, and everyday wellness.**
The app provides a fun and engaging way for kids to explore healthy meals, stay hydrated, build good habits, and receive friendly nutrition guidance with the help of AI.

> 🌱 **NutriBuddy focuses on healthy growth, balanced eating, hydration, and positive habits **

## ✨ Features

* 🍎 **Kid-Friendly Meal Planning** — Explore and organize balanced meal ideas suitable for children.
* 💧 **Water Tracker** — Encourage kids to develop healthy hydration habits.
* 🤖 **AI Nutrition Assistant** — Provides friendly, educational nutrition and meal suggestions.
* 🏆 **Badges & Achievements** — Encourage children to build healthy habits through positive reinforcement.
* 👤 **Profile** — Manage user information and preferences.
* 📱 **Kid-Friendly Interface** — Designed with a simple and engaging mobile experience.


👨‍👩‍👧‍👦 Designed for Kids

NutriBuddy is designed with children in mind.

The goal is to make learning about nutrition simple, positive, and fun. Instead of focusing on weight or appearance, NutriBuddy encourages children to:

🥦 Learn about different nutritious foods
🍽️ Understand the importance of balanced meals
💧 Remember to drink enough water
🌈 Explore a variety of foods
🏃 Build healthy everyday habits
🏆 Celebrate positive progress

NutriBuddy is intended to support healthy development and nutrition education, not dieting or weight management.

🚀 Getting Started
Prerequisites

Make sure you have the following installed:
Node.js
npm
Android Studio if you want to use an Android emulator

1. Clone the repository
2. Navigate to the project
cd NutriBuddy
3. Install dependencies
npm install

4. Configure environment variables
Create a .env file in the root of the project:
GEMINI_API_KEY=your_api_key_here

5. Start the Expo development server
npx expo start

You can then run NutriBuddy using:

📱 Expo Go on a physical device
🤖 Android Emulator


NutriBuddy uses environment variables for API credentials.
Create a local .env file:
GEMINI_API_KEY=your_api_key_here

Running on Android

If you have an Android emulator configured:

npx expo start

Then press:a

You can also scan the Expo QR code using Expo Go on an Android device.
